# Changelog

All notable changes to Blueprint will be documented here.

## [1.0.0] – 2026-08-01

### Added

- Complete redesign of every Pterodactyl admin & user page.
- Modular settings engine with 13 categories and JSON-driven presets.
- Six built-in presets (Blueprint Dark, Slate, Cyberpunk, Solarized Light, Mono, Aurora).
- React 18 component library with Tailwind CSS, Radix UI, Recharts, cmdk and framer-motion.
- Laravel 11 service provider, view composers, blade directives, console commands.
- Command palette (Cmd/Ctrl-K), notification center, theme manager, audit log, security center, monitoring dashboards.
- Custom CSS / JS / HTML injectors under the Advanced settings category.
- Production build pipeline (Vite, Composer, GitHub Actions).
- Documentation (README, INSTALL, BUILD, CUSTOMIZATION, THEME_GUIDE, CHANGELOG).
