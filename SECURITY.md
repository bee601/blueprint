# Security

If you discover a security issue in Blueprint, please email `security@your-org.example.com` instead of opening a public issue. We will respond within 48 hours.

## Reporting

Please include:

- A clear description of the vulnerability
- Steps to reproduce
- Affected versions

## Supported versions

| Version | Supported |
| --- | --- |
| 1.x | Yes |
| 0.x | No |
